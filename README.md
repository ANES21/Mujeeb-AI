## ✨ Features

* 🤖 **System Prompt Switcher:** Seamlessly switch AI personalities (General Assistant, Software Engineer, Proofreader, Professional Translator).
* 🔊 **Text-to-Speech (TTS):** Integrated Web Speech API for audible response reading with Arabic & English support.
* 📋 **One-Click Copy:** Easily copy response content with instant feedback UI.
* 💾 **Export Conversation:** Download full conversation history as a `.txt` file.
* 🗑️ **Clear Chat:** Clean conversation window and reset history instantly.
* ⚡ **Ultra-Fast Responses:** Powered by Groq LPU infrastructure.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js, Groq SDK (`allam-2-7b`)
* **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+), Web Speech API
* **Deployment:** Vercel
